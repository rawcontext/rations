# App review — September 13, 2026

Reviewed the native startup, menu/settings views, account store, provider parsers,
credential discovery, sign-in lifecycle, HTTP transport, subprocess handling, and
build/run configuration. This was a code and regression-test pass; no UI automation
or runtime performance profiling was used.

## Fixes

| Issue | Change |
| --- | --- |
| Duplicate development builds could create multiple menu bar icons and poll the same accounts | Hold an exclusive process lock per bundle ID before initializing the app |
| Background discovery or usage could finish after a fresh sign-in and replace newer state | Version provider activity, ignore obsolete results, and order state publications |
| A slow provider delayed publication of other usage results | Publish individual results after discovery as requests complete |
| Provider discovery could report a cooldown but still trigger usage calls | Preserve typed failures and skip that provider's fetches during its cooldown |
| Subprocess output collection could wait beyond a timeout or caller cancellation | Use bounded nonblocking reads, close unused pipe handles, and stop owned processes |
| Claude's idle terminal was reparsed repeatedly; a session without a reset could borrow the weekly date | Parse only new output, settle the displayed usage, and bound each quota section |
| A reset across New Year could be assigned to the wrong year | Select the nearest year within the supported quota window |
| A malformed Codex reset count could trap during integer conversion | Validate whole nonnegative counts with exact conversion |
| Menu countdowns, refresh labels, and accessibility values could remain frozen while open | Update display time only while the menu is open or a known boundary is reached |
| Expired readings looked current in account detail | Dim stale data consistently and distinguish unavailable usage from disconnected accounts |
| Providers could say Connected despite account errors or a disabled toggle | Show Needs attention or Disabled when appropriate |
| Every preference edit reset the polling timer | Reschedule only when the interval changes; refresh when enabled providers change |

## Settings copy

Removed the Menu bar icon row. Privacy now says only “Emails are redacted in the
menu.” The Providers footer now says only “Saved accounts and credentials stay in
your Mac's Keychain.” Threshold labels use “at or below” to match their inclusive
comparison. The current static icon artwork and attribution are included in Git.

## Verification scope

`make check` covers lint, the zero-duplication policy, builds, and tests.
New cases exercise process-lock exclusivity and release, obsolete provider
results, command timeout/cancellation, inherited output pipes, quota reset
boundaries, malformed reset counts, and Claude section/year parsing. A signed
development build and the native Xcode project are also checked before delivery.

Grok's missing subscription percentage, Antigravity's interactive sign-in window,
and expired inactive-account credentials remain documented provider limitations.
This pass does not claim that browser sign-in for every provider or runtime
performance has been exhaustively tested.
