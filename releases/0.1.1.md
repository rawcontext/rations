# Rations 0.1.1

Your place in line now has an icon.

- Added the graphite app icon with the solid food-and-rations disc from design 1B.
- Built with Apple Icon Composer for glass, light, dark, and tinted appearances.
- Includes a matching icon for macOS 14 and 15.

Download **Rations.dmg**, open it, and drag **Rations** into **Applications**.
Existing installations can use **Check for Updates…**.

Requires macOS 14 or later on Apple Silicon or Intel. The app and installer are
Developer ID signed and notarized. Runtime verification was performed on Apple
Silicon; Intel support is cross-built.
