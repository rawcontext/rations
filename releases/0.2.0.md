# Rations 0.2.0

This release updates the public app to version 0.2.0 (build 4). App features are
unchanged from 0.1.2; the README now includes a screenshot alongside the
installation instructions.

Download **Rations.dmg**, open it, and drag **Rations** into **Applications**.
Existing installations can use **Check for Updates…**.

Requires macOS 14 or later on Apple Silicon or Intel. The app and installer are
Developer ID signed and notarized. Intel support is cross-built; Intel runtime
validation was not performed.
