# Rations 0.1.0

If you have to ask when it resets, you’re already in line.

Rations keeps subscription usage and reset times for Codex, Claude, Antigravity,
Grok, and Cursor in your Mac's menu bar.

- Multiple named accounts per provider.
- Usage meters, reset countdowns, and clear connection status.
- Automatic credential recovery where the vendor supports it.
- Refresh every 15 minutes by default; launch at login is opt-in.
- Signed updates delivered through Sparkle.

## Installation

Download the DMG, open it, and drag Rations into Applications. Requires macOS 14
or later on Apple Silicon or Intel. Install and sign in to the vendor tools you
want Rations to read. macOS may request Keychain access when connecting accounts.

## Current limitations

Provider integrations depend on vendor credentials and usage endpoints. Revoked
or inaccessible credentials can require reconnecting. Grok may supply a reset
date without a usage percentage. Intel is cross-built; runtime verification was
performed on Apple Silicon.
